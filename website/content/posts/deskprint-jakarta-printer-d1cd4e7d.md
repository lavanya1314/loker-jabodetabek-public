<p>di utamankan bisa setting  <strong>(box packaging) </strong>menjadi nilai tambahan </p>
<p><br/></p>
<p>1. Pengolahan &amp; Pemeriksaan File (Pre-Press)</p>
<p>• Verifikasi File: Menerima file dari pelanggan (baik walk-in maupun online) dan mengecek kelayakannya.</p>
<p>• Quality Control (QC) File: Memeriksa resolusi gambar, ukuran (dimensions), area cetak (bleed, margin, crop mark), serta teks untuk menghindari kesalahan (typo).</p>
<p>• Penyesuaian Warna (Color Adjustment): Mengubah atau menyesuaikan mode warna file (biasanya dari RGB ke CMYK) agar hasil cetak mendekati tampilan di layar monitor.</p>
<p>• Layout &amp; Setting (Imposition): Menyusun tata letak (layout) desain pada lembar kerja mesin cetak agar efisien bahan.</p>
<p><br/></p>
<p>2. Desain &amp; Editing Ringan</p>
<p>• Membuat atau mengubah materi desain sederhana (seperti box packaging,spanduk, stiker, kartu nama, atau dokumen) jika ada permintaan dari konsumen.</p>
<p>• Melakukan revisi file cepat jika ada kesalahan dari pelanggan sebelum masuk mesin.</p>
<p><br/></p>
<p>3. Operasional &amp; Koordinasi Produksi</p>
<p>• Mengoperasikan komputer kerja dan mesin cetak digital dasar.</p>
<p>• Berkoordinasi dengan tim produksi (operator mesin besar/finishing) untuk memastikan pesanan berjalan sesuai antrean dan tenggat waktu (deadline).</p>
<p>• Melakukan kontrol kualitas (quality control) pada hasil cetakan sebelum diserahkan ke bagian finishing atau pelanggan.</p>
<p><br/></p>
<p>4. Pelayanan Pelanggan &amp; Administrasi (Opsional tergantung tempat)</p>
<p>• Memberikan konsultasi terkait jenis bahan cetakan, ukuran, dan estimasi waktu pengerjaan kepada pelanggan.</p>
<p>• Mencatat data pesanan, transaksi, dan membuat Surat Perintah Kerja (SPK)</p>
