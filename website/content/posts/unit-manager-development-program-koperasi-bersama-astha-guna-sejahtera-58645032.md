<p><strong>Unit Manager Development Program (UMDP)</strong></p><p>Unit Manager Development Program (UMDP) merupakan program percepatan karier yang dirancang untuk mencetak pemimpin yang kompeten melalui kombinasi pelatihan intensif, coaching, mentoring, serta on-the-job training. Peserta akan mempelajari proses bisnis secara menyeluruh, manajemen tim, strategi penjualan, pelayanan pelanggan, hingga pengelolaan kinerja cabang sebelum dipersiapkan menjadi Unit Manager.</p><p></p><p><strong>Job Description</strong></p><ul><li><p>Mengikuti program pengembangan kepemimpinan secara intensif melalui training, coaching, dan on-the-job training.</p></li><li><p>Mempelajari proses bisnis perusahaan dari operasional, sales, hingga people management.</p></li><li><p>Mendukung pencapaian target bisnis dan operasional unit.</p></li><li><p>Memimpin tim dalam penugasan dan proyek pengembangan.</p></li><li><p>Menganalisis kinerja unit serta memberikan ide perbaikan.</p></li><li><p>Dipersiapkan menjadi Unit Manager setelah menyelesaikan program.</p><p></p><p><strong>Kualifikasi</strong></p></li><li><p>Pendidikan minimal S1 semua jurusan (diutamakan Manajemen pemasaran, Bisnis, Ilmu komunikasi, Teknik industri).</p></li><li><p>Fresh graduate atau pengalaman kerja kurang dari 1 tahun.</p></li><li><p>Mampu mengendarai kendaraan bermotor</p></li><li><p>Memiliki keterarikan di bidang marketing.</p></li><li><p>Memiliki jiwa kepemimpinan, komunikatif, dan mampu bekerja dalam tim.</p></li><li><p>Berorientasi pada target, memiliki kemampuan analitis, dan problem solving yang baik.</p></li><li><p>Bersedia berkomitmen mengikuti seluruh rangkaian program dan ditempatkan di seluruh wilayah operasional perusahaan.</p></li></ul>
